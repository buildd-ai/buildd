# Contributing

Issues are welcome: bug reports, questions and ideas.

Code contributions require signing the [Contributor License Agreement](CLA.md) once. The CLA Assistant check on your first pull request walks you through it; later PRs need nothing more.

For the dev workflow, test commands and the public-repo rule (no production data in code, comments, commits or PR bodies), read [CLAUDE.md](CLAUDE.md). PRs target `dev`.
