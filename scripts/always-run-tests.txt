# Repo-wide invariant tests: always run, whatever the diff.
#
# affected-tests.sh maps a changed source file to the test file NEXT TO IT.
# These tests are not about the file next to them — their input is `git
# ls-files`, i.e. the whole repository — so the change that breaks one of them
# can never select it. They used to run only when some unrelated part of the
# diff tripped the `ALL` fan-out, which is why a forgotten `withCronRun` was
# discovered in CI rather than before the push.
#
# scripts/always-run-tests.test.ts guards this list in both directions. Add an
# entry when you add a test that enumerates the repo; do not remove one to make
# a red build green.
# This file's own gate enumerates the repo too, so it belongs here by its own
# rule — and it is the one entry that must never be dropped, since dropping it
# is what would let the others rot unnoticed.
scripts/always-run-tests.test.ts
scripts/collector-coverage.test.ts
scripts/cron-instrumentation.test.ts
# Enumerates every tracked source file to check that each declared gate slug
# is actually fired somewhere and named in the gate audit. Adding a slug is a
# packages/core change; forgetting to wire it is a change nowhere near this file.
packages/core/__tests__/gate-slug-coverage.test.ts
# Asserts .github/workflows/release-tag.yml. It reads a fixed path rather than
# enumerating the repo, so the ls-files heuristic does not flag it — but a change
# to that workflow still selects no test beside it, which is the same hole.
scripts/release-tag-workflow.test.ts
# Asserts that the claim route still rejects a runner-less body BEFORE it
# assigns work — the property that makes the responder's health probe
# structurally incapable of claiming a real task. Same fixed-path hole: a diff
# to apps/web/src/app/api/workers/claim/route.ts selects the test beside that
# route, never this one, so removing the guard would land green.
apps/responder/src/probes/claim-probe.test.ts
# Enumerates every tracked test file to check that none reaches the operator's
# real home directory. The file that breaks it is a test file anywhere in the
# repo, which is never the file next to this one.
scripts/test-home-isolation.test.ts
# Enumerates the signal registry to check that every signal has a test proving
# it can fire. The signal that breaks it is defined anywhere, so the same
# reasoning applies: this must run even when nothing near it changed.
scripts/signal-fire-coverage.test.ts
# Enumerates the cron job registry to check that every findings-polarity job
# has a test proving it can notify a human. Same reasoning as the signal
# registry above: the job that breaks it can be declared anywhere.
scripts/cron-job-notify-coverage.test.ts
scripts/skills-listed.test.ts
scripts/workflow-safety.test.ts
# Enumerates every tracked schema file to check that hand-built sql
# renders correctly and matches no broken patterns.
scripts/sql-render-coverage.test.ts
# Checks CLAUDE.md's backticked paths, testids and symbols against `git
# ls-files`. The rename or deletion that breaks it lands anywhere in the repo.
scripts/agent-docs-drift.test.ts
