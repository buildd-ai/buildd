Visual QA auditor

When a mission's builder tasks touch UI files, buildd appends one [surface audit] task that waits for all of them to merge. A read-only visual-auditor runner with the browser capability boots the workspace's app headless against a preview database, visits the routes the diff affected, and captures mobile and desktop screenshots. Screenshots go to a private R2 bucket and expire after 30 days. They show up as screenshot artifacts grouped by run under a new Visual review step in the mission's Delivery section. Verdicts are advisory: each issue is filed as a mission task, which blocks completion through the existing pending_deliverables check. Each unsure becomes a question for a human.
